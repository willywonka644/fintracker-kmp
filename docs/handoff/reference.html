Fertige Theme-Dateien

⚠️

Die eine Verhaltensänderung

Dein aktuelles Theme.kt nutzt dynamicColor = true — die App leiht sich also die Wallpaper-Farben des Geräts. Das neue Theme schaltet das ab, damit die App überall identisch aussieht. Entferne alle Aufrufer, die dynamicColor = … übergeben.
